# AI-Project-Panopticon
AI-based project for intelligent exam proctoring and monitoring.

## Overview

Project Panopticon is an AI-powered examination monitoring system
designed to assist in detecting suspicious activities during online
examinations.

## Features

- AI-based monitoring
- Face detection
- Examination activity analysis
- Suspicious activity detection
- Automated monitoring

## Technologies

- Python
- Jupyter Notebook
- Machine Learning
- Computer Vision

## Project Structure

AI-Project-Panopticon/
├── Project_Panopticon.ipynb
├── README.md
└── requirements.txt

## How to Run

1. Clone the repository.
2. Install the required dependencies.
3. Open the Jupyter Notebook.
4. Run the notebook cells.

## Future Scope

The project can be extended with real-time monitoring,
improved detection models and a web-based examination interface.
